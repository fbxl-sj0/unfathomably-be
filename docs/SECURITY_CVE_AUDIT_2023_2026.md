# Security CVE Audit: Mastodon and Pleroma

Audit date: 2026-08-13

This audit reconciles the complete published inventory through the audit date:
47 Mastodon CVEs and one Pleroma CVE. The earlier count of 47 combined records
came from a publication-year query that omitted a later Mastodon advisory.
FFmpeg CVE-2026-8461 is tracked separately because it affects a runtime media
dependency rather than the Unfathomably application source.

The result is not based on package names or version comparisons alone. Each
issue was mapped to the equivalent Unfathomably data flow, authentication
boundary, parser, network client, or deployment dependency.

## Disposition legend

- **Fixed**: this audit added or strengthened a source-level control.
- **Covered**: the relevant behavior was already protected and was reviewed.
- **Not applicable**: Unfathomably does not implement the vulnerable Mastodon
  feature or does not use the vulnerable representation.

## Mastodon CVEs

| CVE | Upstream issue | Disposition in Unfathomably |
| --- | --- | --- |
| CVE-2022-48364 | Moderator identity disclosure while approving sensitive-content appeals | **Not applicable.** There is no Mastodon appeal service or representative-account workflow. |
| CVE-2023-28853 | Blind LDAP filter injection | **Covered.** LDAP filters are built with the LDAP encoder rather than interpolating raw credentials. |
| CVE-2023-36459 | Stored XSS through oEmbed preview cards | **Covered.** Remote card HTML is sanitized and unsafe embeds are not rendered as trusted markup. |
| CVE-2023-36460 | Arbitrary file creation through media attachments | **Covered.** Upload paths are generated by the uploader and validated independently of remote filenames. |
| CVE-2023-36461 | Denial of service through slow HTTP responses | **Covered.** HTTP pools, adapters, and remote-content jobs use bounded timeouts. |
| CVE-2023-36462 | Misleading formatting of verified profile links | **Covered.** `rel=me` verification is tied to sanitized profile links and exact target URLs. |
| CVE-2023-42450 | Server-side request forgery | **Fixed.** Outbound ActivityPub, FASP, rich-media, WebFinger, and reverse-proxy requests reject non-public destinations before connecting. |
| CVE-2023-42451 | Invalid domain-name normalization | **Covered.** Remote hosts pass through URI parsing, IDNA normalization, and canonical host comparison. |
| CVE-2023-42452 | Stored XSS through translated content | **Covered.** Translated HTML is scrubbed before it is cached or rendered. |
| CVE-2023-49952 | Rate-limit bypass through forwarded-address headers | **Covered.** Trusted-proxy processing supplies a parsed client address; arbitrary forwarding headers are not identities. |
| CVE-2024-23832 | Remote user impersonation and account takeover | **Covered.** Remote actor updates retain actor ownership and origin checks and cannot update local users. |
| CVE-2024-25618 | OpenID Connect account takeover by email change | **Not applicable.** There is no Mastodon OpenID Connect account-linking implementation. |
| CVE-2024-25619 | Destroyed OAuth applications leave streaming tokens active | **Fixed.** Token and application deletion disconnect associated streams, and sockets periodically revalidate token state. |
| CVE-2024-25623 | ActivityStreams media-type confusion permits impersonation | **Covered.** ActivityPub fetches validate response media and actor/object validators enforce ownership. |
| CVE-2024-34535 | API rate-limit bypass through a crafted request header | **Covered.** Identities come from parsed connection metadata, authenticated users, or normalized parameters. |
| CVE-2024-37903 | Authorship bypass in an audience extension | **Not applicable.** The vulnerable Mastodon audience-extension update path is not implemented. |
| CVE-2025-27157 | Missing confirmation-email rate limit | **Fixed.** Confirmation resends are limited by both client address and normalized destination account. |
| CVE-2025-27399 | Domain-block rationale ignores approval visibility | **Not applicable.** The Mastodon user-approval domain-block disclosure workflow is absent. |
| CVE-2025-54879 | Confirmation-email throttle can be bypassed | **Fixed.** Destination throttling prevents source-address rotation from repeatedly targeting one account. |
| CVE-2025-62174 | Password changes do not revoke sessions and access tokens | **Fixed.** Password reset invalidates OAuth tokens transactionally and disconnects their streams. |
| CVE-2025-62175 | Disabled accounts retain streaming access | **Fixed.** Connect and ping revalidate the token and active user; account deactivation also closes streams. |
| CVE-2025-62176 | Streaming subscriptions without the required read scope | **Fixed.** Protected streams retain scope checks, lifecycle validation, and the anonymous-federation restriction. |
| CVE-2025-62605 | Quote-control bypass | **Covered.** Quote authorization is evaluated against the quoted object and its owning actor before publication. |
| CVE-2025-67500 | Private-post existence oracle through inconsistent errors | **Covered.** Lookup applies visibility before rendering and returns not found for inaccessible objects. |
| CVE-2026-22245 | SSRF protection bypass through special address ranges | **Fixed.** All resolved A and AAAA records are checked against explicit public-address rules. |
| CVE-2026-22246 | Other users' severed relationships are enumerable | **Not applicable.** The Mastodon severed-relationship API and storage model are absent. |
| CVE-2026-23961 | Remote suspension bypass | **Covered.** Refreshes cannot reactivate locally deactivated actors; signed inboxes reject inactive actors. |
| CVE-2026-23962 | Oversized remote poll denial of service | **Fixed.** Combined remote poll choices are capped before object acceptance. |
| CVE-2026-23963 | Missing list and filter length limits | **Fixed.** List names and counts are bounded; filter changesets already bound titles, keywords, and terms. |
| CVE-2026-23964 | Push-notification settings IDOR | **Covered.** Subscriptions are selected through the authenticated token and user, not a supplied identifier. |
| CVE-2026-25540 | Signature-dependent collections cached under shared keys | **Covered.** Signed collections use authorization-aware queries and no signature-independent response cache. |
| CVE-2026-27468 | Unconfirmed FASP can create subscriptions | **Covered.** FASP operations require an approved registration; registration alone grants no subscription authority. |
| CVE-2026-27477 | FASP registration SSRF | **Fixed.** Registration validates a public base URL; requests repeat validation and disable redirects. |
| CVE-2026-33868 | Open redirect through Mastodon's `/web/` route | **Not applicable.** This route and redirect behavior are absent. |
| CVE-2026-33869 | Quote-authorization denial of service | **Covered.** Quote authorization uses bounded local lookups and asynchronous remote-fetch controls. |
| CVE-2026-41259 | Insufficient email-address verification | **Fixed.** Percent-routing addresses are rejected and confirmation limits use a normalized destination. |
| CVE-2026-46348 | SSRF bypass through IPv6 unspecified address | **Fixed.** `::` and its loopback and unspecified forms are rejected. |
| CVE-2026-46349 | LD-signature bypass through JSON-LD named graphs | **Not applicable.** Verification binds the canonical source document and does not use RDF dataset canonicalization. |
| CVE-2026-47389 | SSRF bypass through IPv4-mapped IPv6 | **Fixed.** Mapped addresses are normalized and their embedded IPv4 address must be public. |
| CVE-2026-47777 | Consent bypass in remote collections | **Covered.** Collection authorization confirms the owner and does not trust remote capability claims alone. |
| CVE-2026-48028 | Removal of integrity-protected JSON from signed activities | **Not applicable.** Verification binds the fetched document instead of reconstructing a lossy RDF graph. |
| CVE-2026-50128 | Spoofed attribution domains in signed activities | **Not applicable.** Attribution uses exact actor URI and origin relationships, not an RDF-derived display domain. |
| CVE-2026-50129 | MathML transformer denial of service | **Covered.** Unsupported MathML is removed by the sanitizer; malformed markup is regression-tested. |
| CVE-2026-59825 | LDAP configuration disables TLS verification | **Fixed.** Certificate and hostname checks override insecure LDAP adapter options. |
| CVE-2026-72914 | Unauthenticated statistics denial of service | **Covered.** Administrative statistics remain behind the authenticated admin pipeline. |
| CVE-2026-72915 | Collection-administration PII disclosure | **Not applicable.** The vulnerable serializer and endpoint are absent. |
| CVE-2026-72916 | SSRF bypass through IPv4-compatible IPv6 | **Fixed.** Compatible, mapped, NAT64, 6to4, ORCHID, documentation, link-local, loopback, and private ranges are rejected. |

## Runtime dependency finding

FFmpeg CVE-2026-8461 affects the Ubuntu 24.04 FFmpeg 6.1.1 package used by the
live host. `build_scripts/install-secure-ffmpeg.sh` verifies the official
FFmpeg signing key and release signature, builds fixed FFmpeg 6.1.6 under
`/opt`, and exposes its tools through `/usr/local/bin` until the distribution
package is fixed.

## Regression and release evidence

- `test/pleroma/security/cve_regression_test.exs` covers special-address SSRF,
  URL credentials, remote poll and list limits, special email routing,
  malformed MathML, expired streaming tokens, restricted anonymous streams,
  and destination-based throttling.
- Existing ActivityPub, OAuth, streaming, sanitizer, LDAP, uploader, emoji,
  and visibility tests remain part of the full backend test suite.
- Warning-free compilation, strict Credo, dependency auditing, the backend
  suite, and frontend lint, type, test, and production-build gates are required
  before deployment.
